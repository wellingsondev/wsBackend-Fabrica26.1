# wsBackend-Fabrica26.1

⚡ Hogwarts Express - Django Project

Este é um projeto academico desenvolvido em python usando o framework Django,

funcionalidades do projeto

**Listagem de personagem: exibição dos bruxos vindo da api externa, 
**Filtro por casa: onde é feita a seleção dinamica das casa onde o personagem pertence e exibe so personagens
pertencentes a casa selecionada
**Detalhamento do personagem: onde é feita o detalhamento desse personagem em uma pagina individula
**Sistema de favorito: que tem com funcionalidade adicionar um determinado personagem a sua lista onde 
ele pode acessar essa lista que esta sendo salva no banco de dados se ele quiser ele pode ta fazendo a exclusão
do personagem da sua lista

🛠️ Tecnologias usadas nesse projeto
**Backend: python e Django
**Frontend: HTML5, CSS3, e Bootstrap5
**Api externa: [HP-API](https://hp-api.onrender.com/)
**Banco de dados: Sqlite
